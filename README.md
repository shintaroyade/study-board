# 英語勉強会ボード

英文法の勉強会とメンバー授業の予定・出欠・出席ランキング・ストリーク・文法の進捗を、仲間で共有するWebアプリです。
予定はログインなしで誰でも見られます。メールアドレスとパスワードで登録・ログインすると、出欠の返事、ランキング、メンバー一覧、自分だけのホーム(参加記録・目標メモ・文法の理解度 ◎○△)が使えます。

- 見た目:GitHub Pages
- データ:Firebase(Cloud Firestore)

## はじめての設定(約10分)

### 1. Firebaseのプロジェクトを作る
1. https://console.firebase.google.com を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 名前は何でもOK(例:study-board)
3. Googleアナリティクスはオフでかまいません

### 2. データベース(Firestore)を作る
1. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは **asia-northeast1(東京)** を選ぶ
3. 「本番環境モード」で作成
4. 作成後、上のタブ「ルール」を開き、このリポジトリの `firestore.rules` の中身をすべて貼り付けて「公開」

### 3. Webアプリを登録して設定をコピーする
1. 左上の歯車 →「プロジェクトの設定」
2. 下の「マイアプリ」で `</>`(ウェブ)アイコンを押す
3. ニックネームを入れて「アプリを登録」(Firebase Hostingのチェックは不要)
4. 表示される `const firebaseConfig = { ... }` の **{ } の中身** をコピー
5. このリポジトリの `firebase-config.js` を開き、`{ }` の中を貼り付けたものに置き換えて保存(GitHubのサイト上で鉛筆アイコンから編集できます)

### 4. GitHub Pagesで公開する
1. リポジトリの「Settings」→「Pages」
2. 「Source」を **Deploy from a branch**、Branchを **main / (root)** にして「Save」
3. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
4. そのURLをLINEグループに貼れば完了

## 使い方
- 初めての人は「新規登録」(名前・得意分野・招待コード・メールアドレス・パスワード)。次からは「ログイン」
- 招待コードは管理者(森山さん)が設定画面で決めます。コードがないと登録できません
- パスワードを忘れたら、ログイン画面の「パスワードを忘れた場合」から再設定メールを送れます
- ログイン後のホームは自分専用。目標メモと文法の理解度(◎○△)は本人にしか見えません
- 予定は右下の「+」から追加。「場所から作る」でGoogleマップのリンクを自動作成
- 「LINE用にコピー」で予定の告知文をコピー。ホームの「まとめてLINEコピー」で今週分まとめて
- 勉強会のあと、予定の詳細で実際に来た人をチェック → ランキング・🔥ストリーク・バッジに反映
- 勉強会の名前は左上をタップした設定画面から変更
- 「参加」を押すと予約確定画面が出て、Googleカレンダー/iPhoneなどのカレンダーに追加できます。確認メールも届きます
- 予定が追加されると、メンバー全員にメールでお知らせが届きます(設定でオフにできます)
- 勉強会の時間中(開始30分前〜終了3時間後)は、自分で「出席する」を押せます
- 勉強会のあとは予定の詳細から「ふりかえり」:今日学んだこと(みんなに公開)、英文法の回は「よかったこと/次回やりたいこと」、メンバー授業は担当者だけに届く「よかった点/もっと知りたい点」
- 「テーマ」タブ:聞きたいテーマを投稿して👍で投票。教えられる人が名乗り出て、そのままメンバー授業の予定にできます
- 予定を削除できるのは、作った人と管理者だけです

## メール送信のしくみ
`mailer/Code.gs` を Google Apps Script で動かしています。1分ごとにデータベースを確認し、新しい予定のお知らせと予約確定メール(カレンダー用の .ics 付き)を送ります。送信元は Apps Script を動かしている Google アカウントの Gmail です。

## 注意
- 予定(日時・場所・内容)はURLを知っている人なら誰でも見られます。メンバー名や出欠はログインした人だけに見えます
- 登録は誰でもできるので、URLは仲間内だけで共有してください
- Firebaseの無料枠(Sparkプラン)で十分に動きます。クレジットカードの登録は不要です
